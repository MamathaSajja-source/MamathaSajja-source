### 🧠 AI-Powered Customer Feedback Analyzer
> An NLP system that automatically converts unstructured customer reviews into structured business insights — no manual reading required.

- 🔍 Identified key complaint categories: quality, battery, and charging issues
- 🏠 Found Home & Kitchen as the top complaint category
